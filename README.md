# The 3AM Fridge Text

**3am. I opened the fridge for water and stood in its light like a raccoon at a crime scene, apologizing to the leftovers for eating their friend.**

A 3AM fridge raid told like a police report. The fridge light is the
interrogation lamp, the snacker is a raccoon caught at the scene, and the
punchline is the apology — not to a person, but to the leftovers, for
eating their friend. It reads like a text sent at 3AM because it is one:
short, unfiltered, and already regretting itself. One image, one twist,
and a confession nobody asked for at an hour nobody should be texting
about. Nothing here is clever for its own sake; the line is plain on
purpose, so the picture lands instead of the trick.

## Run it

```sh
node main.ts
```

Writes the one-liner (144 characters + trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`). Pure
Node 24 stdlib, deterministic, no network.
